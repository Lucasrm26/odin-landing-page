A landing page presenting a Brazilian Jiu-Jitsu course, focusing on core mechanics, leverage, and the fundamental pillars of the Gentle Art. Developed as part of **The Odin Project** curriculum.

🔗 **[Live Demo / Preview](https://lucasrm26.github.io/odin-landing-page/)**


## 💡 Key Learnings
- Using Flexbox in practical situations.
- Applying proper HTML semantic structure.
- Building a webpage from a design reference.
- Expanding knowledge of Git and version control.
- Preventing layout shifts during image loading.
